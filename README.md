# SuperCars Design 2.0

Elegantna spletna stran o super avtomobilih z Apple-style dizajnom in animacijami.

## Vsebina

- **Lamborghini** – glavni fokus na dizajn
- **Ferrari**, **Porsche**, **BMW**, **Mercedes-AMG**
- **Super SUV** (Purosangue, Urus, iX, G 63, kitajski SUV)
- **Tesla** (Model S, 3, X, Y, novi Roadster, Cybertruck)
- **Notranjosti** – 25 luksuznih kabin
- **Prototipi** – futuristični koncepti
- **Zgodovina** – od Benz 1886 do danes

## Kako zagnati

Odpri `index.html` v brskalniku.

## Tehnologije

- Čisti HTML / CSS / JS
- Animirano ozadje, particles, smooth scroll, Intersection Observer
- Responsivni Apple-inspired UI

Ustvarjeno z ❤️ za ljubitelje superšportnikov.
